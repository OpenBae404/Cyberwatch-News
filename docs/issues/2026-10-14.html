1. KNOWN EXPLOITED -- CVE-2015-3306

KNOWN EXPLOITED CRITICAL CVSS 10.0 published 2015-05-18

KNOWN EXPLOITED. CISA lists this as known-exploited in ProFTPD on 2026-10-08, so it is being used against people now -- that outranks severity.

What happened: The mod_copy module in ProFTPD 1.3.5 allows remote attackers to read and write arbitrary files using the site cpfr and site cpto commands.

How serious: This vulnerability is rated as critical with a perfect CVSS score of 10.0, enabling full remote file system compromise.

What to do: Apply the available patches from your distribution or vendor to update ProFTPD and mitigate the risk of unauthorized file access.

KNOWN EXPLOITED. CISA lists this as known-exploited in ONLYOFFICE Docs on 2026-10-08, so it is being used against people now -- that outranks severity.

5. KNOWN EXPLOITED -- CVE-2016-3081

KNOWN EXPLOITED HIGH CVSS 8.1 published 2016-04-26

KNOWN EXPLOITED. CISA lists this as known-exploited in Apache Struts on 2026-10-08, so it is being used against people now -- that outranks severity.

What happened: A vulnerability in Apache Struts versions 2.3.19 through 2.3.28 allows remote attackers to execute arbitrary code when Dynamic Method Invocation is enabled. Attackers can exploit chained expressions using the method: prefix to achieve remote code execution.

Who is affected: Users running Apache Struts 2.3.19 to 2.3.28 with Dynamic Method Invocation enabled are directly affected. Additionally, Huawei products including Agile Controller-Campus, AnyOffice, LogCenter, FireHunter6000, and various OceanStor firmware versions are impacted.

How serious: The issue is rated as high severity with a CVSS score of 8.1, indicating significant risk to confidentiality, integrity, and availability. Remote code execution capability makes this a critical threat for exposed applications.

What to do: Administrators should upgrade Apache Struts to a version outside the affected range or disable Dynamic Method Invocation if possible. Organizations using the listed Huawei products should consult the vendor security advisories for specific mitigation steps.

Why this is here: Known exploited -- CISA lists this as known-exploited in Apache Struts on 2026-10-08, so it is being used against people now -- that outranks severity. HIGH (CVSS 8.1); reach unrated (no entry in the reach table).
