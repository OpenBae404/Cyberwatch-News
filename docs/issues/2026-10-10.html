1. KNOWN EXPLOITED -- CVE-2015-3306

KNOWN EXPLOITED CRITICAL CVSS 10.0 published 2015-05-18

KNOWN EXPLOITED. CISA lists this as known-exploited in ProFTPD on 2026-10-08, so it is being used against people now -- that outranks severity.

What happened: The mod_copy module in ProFTPD 1.3.5 allows remote attackers to read and write arbitrary files using the site cpfr and site cpto commands.

Who is affected: Users running ProFTPD 1.3.5 or distributions such as Fedora, Debian, openSUSE Tumbleweed, and SUSE Linux Enterprise Server that package this vulnerable version.

How serious: The vulnerability is rated critical with a perfect CVSS score of 10.0, indicating it can be exploited remotely without authentication to fully compromise confidentiality, integrity, and availability.

What to do: Apply the available patches from your distribution or vendor to update ProFTPD and mitigate the risk of unauthorized file access and modification.

4. KNOWN EXPLOITED -- CVE-2016-3081

KNOWN EXPLOITED HIGH CVSS 8.1 published 2016-04-26

KNOWN EXPLOITED. CISA lists this as known-exploited in Apache Struts on 2026-10-08, so it is being used against people now -- that outranks severity.

What happened: A vulnerability in Apache Struts versions 2.3.19 through 2.3.28 allows remote attackers to execute arbitrary code when Dynamic Method Invocation is enabled. Attackers can exploit chained expressions using the method: prefix to achieve this remote code execution.

Who is affected: Users running Apache Struts versions 2.3.19 to 2.3.28 with Dynamic Method Invocation enabled are directly affected. Additionally, Huawei products including Agile Controller-Campus, AnyOffice, LogCenter, FireHunter6000, and various OceanStor firmware versions are impacted.

How serious: The vulnerability carries a high severity rating with a CVSS score of 8.1, indicating significant risk to confidentiality, integrity, and availability. It allows unauthenticated remote attackers to execute arbitrary code on the affected system.

What to do: Administrators should upgrade Apache Struts to a version outside the affected range or disable Dynamic Method Invocation if upgrading is not immediately possible. Huawei customers should consult the official security advisory for updates regarding their specific products.

Why this is here: Known exploited -- CISA lists this as known-exploited in Apache Struts on 2026-10-08, so it is being used against people now -- that outranks severity. HIGH (CVSS 8.1); reach unrated (no entry in the reach table).

5. KNOWN EXPLOITED -- CVE-2023-22894

KNOWN EXPLOITED MEDIUM CVSS 4.9 published 2023-04-19

KNOWN EXPLOITED. CISA lists this as known-exploited in Strapi on 2026-10-08, so it is being used against people now -- that outranks severity.

What happened: Strapi versions through 4.5.5 allow attackers with admin panel access to discover sensitive user details by exploiting the query filter. This vulnerability enables the inference of values from API responses, potentially exposing password hashes and reset tokens for super admins or sensitive data for lower-privileged users.

Who is affected: Organizations running Strapi versions 4.5.5 and earlier that grant admin panel access to users. This includes environments where attackers might have super admin privileges or access to accounts with permissions to view username and email information.

How serious: The issue is rated as medium severity with a CVSS score of 4.9. It poses a significant risk to confidentiality as it allows the extraction of sensitive user information and authentication credentials.

What to do: Update Strapi to a version later than 4.5.5 to resolve the query filter exploitation. Review access controls to ensure that admin panel access is restricted to trusted users and that sensitive data is not unnecessarily exposed through API responses.

Why this is here: Known exploited -- CISA lists this as known-exploited in Strapi on 2026-10-08, so it is being used against people now -- that outranks severity. MEDIUM (CVSS 4.9); reach unrated (no entry in the reach table).
