5. CVE-2026-21589

CRITICAL CVSS 9.3 published 2026-10-05

What happened: An arbitrary file access vulnerability in Atlassian Data Center products allows unauthenticated attackers to read specific files within the web application root directory if they know the exact file path. This flaw does not permit directory enumeration, limiting exploitation to targets with known sensitive file locations.

Who is affected: Users running Atlassian Bitbucket, Confluence, Jira Software, Jira Service Management, Bamboo, Crowd, Crucible, or Fisheye Data Center versions prior to the specified fix releases.

How serious: The vulnerability is rated Critical with a CVSS score of 9.3, as it enables high confidentiality and integrity impacts for sensitive files in certain configurations.

What to do: Upgrade affected products to the fixed versions listed in the vendor advisory, such as Bitbucket 9.4.26 or Jira Software 9.12.40, to resolve the issue.

Why this is here: Severity-chosen -- not in the CISA KEV catalogue, selected on severity and reach. CRITICAL (CVSS 9.3); reach 51/100 via "confluence".
