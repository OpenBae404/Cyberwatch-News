1. KNOWN EXPLOITED -- CVE-2026-104935

KNOWN EXPLOITED HIGH CVSS 8.6 published 2026-10-13

KNOWN EXPLOITED. CISA lists this as known-exploited in Ivanti Connect Secure on 2026-10-13, so it is being used against people now -- that outranks severity.

What happened: A remote unauthenticated attacker can bypass authentication by spoofing in Ivanti Connect Secure versions before 25.1.3.0 to execute arbitrary commands. This vulnerability does not affect Ivanti Connect Secure version 22.7R2.14 or prior.

How serious: The vulnerability is rated HIGH severity with a CVSS score of 8.6, allowing remote command execution without authentication.

What to do: Administrators should review the official Ivanti security advisory and CISA catalog entry for guidance on mitigating this known exploited vulnerability.

4. CVE-2026-105445

CRITICAL CVSS 9.4 published 2026-10-13

What happened: An incorrect privilege assignment in Docker Hub's account-to-organization conversion feature allowed an authenticated attacker to reassign a personal access token to another user without revoking the original secret. This enabled the attacker to authenticate as the recipient and pull, push, or delete images within the user's accessible repositories.

Who is affected: Users of Docker Hub who utilize the account-to-organization conversion feature or manage personal access tokens with access to organization repositories.

How serious: The vulnerability is rated Critical with a CVSS score of 9.4, indicating high potential for complete confidentiality, integrity, and availability impact.

What to do: Review the official Docker security advisory for details on mitigation steps and monitor for any updates regarding token rotation or revocation procedures.

Why this is here: Severity-chosen -- not in the CISA KEV catalogue, selected on severity and reach. CRITICAL (CVSS 9.4); reach 76/100 via "docker".
