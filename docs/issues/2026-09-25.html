1. KNOWN EXPLOITED -- CVE-2025-39682

KNOWN EXPLOITED CRITICAL CVSS 9.8 published 2025-09-05

KNOWN EXPLOITED. CISA lists this as known-exploited in Linux Kernel on 2026-09-18, so it is being used against people now -- that outranks severity.

What happened: A critical flaw in the Linux kernel's TLS implementation mishandles zero-length records on the receive list, potentially causing processing errors during message reception. Who is affected: Users running the Linux kernel with TLS enabled are affected, including systems using Debian Linux and Siemens SIMATIC CN 4100 firmware.

How serious: The vulnerability is rated Critical with a CVSS score of 9.8, indicating it allows for complete compromise of confidentiality, integrity, and availability.

What to do: Apply the stable kernel patches linked in the references to resolve the TLS record handling issue.

2. KNOWN EXPLOITED -- CVE-2026-94127

KNOWN EXPLOITED CRITICAL CVSS 9.3 published 2026-09-22

KNOWN EXPLOITED. CISA lists this as known-exploited in F5 BIG-IP APM on 2026-09-22, so it is being used against people now -- that outranks severity.

What happened: A vulnerability in F5 BIG-IP APM allows unauthenticated remote code execution when the system is configured as an OAuth Authorization Server. The flaw exists in the data plane and does not affect the control plane.

Who is affected: Organizations running F5 BIG-IP with APM configured specifically as an OAuth Authorization Server are at risk. Deployments using APM strictly as an OAuth Client or Resource Server without authorization server profiles are not affected.

How serious: This is a critical vulnerability with a CVSS score of 9.3 that enables remote code execution by unauthenticated attackers. The impact is severe as it allows full system compromise on the data plane.

What to do: Review your BIG-IP configuration to determine if the OAuth Authorization Server profile is enabled. Apply the vendor-recommended patch or mitigation steps outlined in the official security advisory.

Why this is here: Known exploited -- CISA lists this as known-exploited in F5 BIG-IP APM on 2026-09-22, so it is being used against people now -- that outranks severity. CRITICAL (CVSS 9.3); reach 56/100 via "big-ip".
