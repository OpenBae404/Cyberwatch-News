1. KNOWN EXPLOITED -- CVE-2015-3306

KNOWN EXPLOITED CRITICAL CVSS 10.0 published 2015-05-18

KNOWN EXPLOITED. CISA lists this as known-exploited in ProFTPD on 2026-10-08, so it is being used against people now -- that outranks severity.

What happened: A critical vulnerability in the mod_copy module of ProFTPD 1.3.5 allows remote attackers to read and write arbitrary files using the site cpfr and site cpto commands.

How serious: The issue is rated as critical with a perfect CVSS score of 10.0, indicating that attackers can fully compromise confidentiality, integrity, and availability without authentication.

What to do: Administrators should apply available patches from their distribution vendors or upgrade ProFTPD to a version where this vulnerability is resolved.

2. KNOWN EXPLOITED -- CVE-2021-3199

KNOWN EXPLOITED CRITICAL CVSS 9.8 published 2021-01-26

KNOWN EXPLOITED. CISA lists this as known-exploited in ONLYOFFICE Docs on 2026-10-08, so it is being used against people now -- that outranks severity.

What happened: A directory traversal vulnerability in ONLYOFFICE Document Server before version 5.6.3 allows remote code execution via a crafted image upload parameter when JWT is enabled. Attackers can exploit this by injecting a /.. sequence into the upload endpoint to execute arbitrary commands on the server.

Who is affected: Organizations running ONLYOFFICE Document Server versions prior to 5.6.3 with JWT authentication enabled are at risk.

How serious: The vulnerability is rated Critical with a CVSS score of 9.8, indicating a high likelihood of successful exploitation leading to complete system compromise.

What to do: Administrators should upgrade ONLYOFFICE Document Server to version 5.6.3 or later to mitigate this risk immediately.

Why this is here: Known exploited -- CISA lists this as known-exploited in ONLYOFFICE Docs on 2026-10-08, so it is being used against people now -- that outranks severity. CRITICAL (CVSS 9.8); reach unrated (no entry in the reach table).

3. KNOWN EXPLOITED -- CVE-2016-3081

KNOWN EXPLOITED HIGH CVSS 8.1 published 2016-04-26

KNOWN EXPLOITED. CISA lists this as known-exploited in Apache Struts on 2026-10-08, so it is being used against people now -- that outranks severity.

What happened: A vulnerability in Apache Struts versions 2.3.19 through 2.3.28 allows remote code execution when Dynamic Method Invocation is enabled. Attackers can exploit chained expressions using the method: prefix to run arbitrary commands on the affected server.

Who is affected: Organizations running Apache Struts 2.3.19 to 2.3.28 with Dynamic Method Invocation enabled are directly at risk. Additionally, Huawei products including Agile Controller-Campus, AnyOffice, Logcenter, Firehunter6000, and various OceanStor firmware versions are affected.

How serious: The issue carries a high severity rating with a CVSS score of 8.1, indicating significant potential for complete system compromise. Remote attackers can achieve high impact on confidentiality, integrity, and availability without requiring authentication.

What to do: Administrators should disable Dynamic Method Invocation in Apache Struts configurations or upgrade to a patched version immediately. Users of the listed Huawei products should apply the security updates provided by the vendor as soon as possible.

Why this is here: Known exploited -- CISA lists this as known-exploited in Apache Struts on 2026-10-08, so it is being used against people now -- that outranks severity. HIGH (CVSS 8.1); reach unrated (no entry in the reach table).

4. KNOWN EXPLOITED -- CVE-2023-22894

KNOWN EXPLOITED MEDIUM CVSS 4.9 published 2023-04-19

KNOWN EXPLOITED. CISA lists this as known-exploited in Strapi on 2026-10-08, so it is being used against people now -- that outranks severity.

What happened: Strapi versions through 4.5.5 contain a vulnerability allowing authenticated attackers to infer sensitive user details by exploiting query filters on the admin panel. This can lead to the discovery of password hashes and reset tokens for super admins or sensitive information for lower-privileged API users.

Who is affected: Organizations running Strapi versions 4.5.5 and earlier that expose the admin panel to users with varying levels of access.

How serious: The issue is rated as medium severity with a CVSS score of 4.9, primarily impacting confidentiality by exposing sensitive user data.

What to do: Update Strapi to a patched version to prevent unauthorized inference of sensitive user information through query filters.

Why this is here: Known exploited -- CISA lists this as known-exploited in Strapi on 2026-10-08, so it is being used against people now -- that outranks severity. MEDIUM (CVSS 4.9); reach unrated (no entry in the reach table).
