1. KNOWN EXPLOITED -- CVE-2026-94127

KNOWN EXPLOITED CRITICAL CVSS 9.3 published 2026-09-22

KNOWN EXPLOITED. CISA lists this as known-exploited in F5 BIG-IP APM on 2026-09-22, so it is being used against people now -- that outranks severity.

What happened: A critical vulnerability in F5 BIG-IP allows unauthenticated remote code execution when the device is configured as an OAuth Authorization Server. The flaw exists in the data plane and does not expose the control plane.

Who is affected: Organizations running F5 BIG-IP with APM configured specifically as an OAuth Authorization Server are at risk. Deployments using APM only as an OAuth Client or Resource Server are not affected.

How serious: The issue is rated Critical with a CVSS score of 9.3, enabling full remote code execution by an unauthenticated attacker. This applies to both software and appliance modes of the affected configuration.

What to do: Review your BIG-IP configuration to determine if it acts as an OAuth Authorization Server. If so, apply the relevant patch or mitigation as detailed in the vendor advisory and CISA catalog entry.

Why this is here: Known exploited -- CISA lists this as known-exploited in F5 BIG-IP APM on 2026-09-22, so it is being used against people now -- that outranks severity. CRITICAL (CVSS 9.3); reach 56/100 via "big-ip".

How serious: The vulnerability is rated Critical with a CVSS score of 10.0, enabling remote attackers to achieve complete system compromise without authentication.

What to do: Review the official WSO2 security advisory for details on mitigation and patching steps to secure your JWT implementation.

Why this is here: Known exploited -- CISA lists this as known-exploited in WSO2 Multiple Products on 2026-09-24, so it is being used against people now -- that outranks severity. CRITICAL (CVSS 10.0); reach unrated (no entry in the reach table).
