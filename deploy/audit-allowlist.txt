# What this repository is allowed to publish.
#
# Format:  <label>|<path>   # why it is safe
# One line per accepted finding of tools/public_repo_audit.py. A finding that is
# not listed here fails the audit, including a new one of a kind already
# accepted in another file -- that is the point of the file.
#
# Credential findings ("secret" severity) can NOT be listed here. Those get
# removed and the credential rotated.
#
# ---------------------------------------------------------------------------
# JUDGEMENT CALL ON RECORD: `localhost:8001`
#
# The newsletter's summaries are written by a model on the author's home
# network, and the issue footer names the endpoint so a reader can tell whether
# a summary was written or fell back to raw NVD text. `localhost` is an mDNS
# name: it resolves on that LAN and nowhere else, and it is not a credential.
# Accepted in the repository for that reason.
#
# It is NOT accepted on the published site. src/site.py redacts every URL
# pointing at a non-public host before it reaches docs/, and
# tests/test_site.py:TestPublicRepoHygiene proves it for the page and the feed.
# So the code is readable by anyone cloning the repo, and a visitor to
# cyberwatch.asutera.dev sees "[internal endpoint redacted]".
#
# If that trade is not wanted, the fix is to set CYBERWATCH_LLM_BASE_URL in the
# launchd plist and drop the literal from run.py and README.md -- not to widen
# this file.
# ---------------------------------------------------------------------------
