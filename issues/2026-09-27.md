`KNOWN EXPLOITED` `CRITICAL` `CVSS 9.3` `published 2026-09-22`

> **KNOWN EXPLOITED.** CISA lists this as known-exploited in F5 BIG-IP APM on 2026-09-22, so it is being used against people now -- that outranks severity.

**What happened:** A critical vulnerability in F5 BIG-IP APM allows unauthenticated remote code execution when the system is configured as an OAuth Authorization Server. The flaw exists in the data plane and does not expose the control plane.

**Who is affected:** Administrators running F5 BIG-IP with APM configured specifically as an OAuth Authorization Server are at risk. Deployments using APM strictly as an OAuth Client or Resource Server without authorization server profiles are not affected.

**What to do:** Review your F5 BIG-IP configuration to determine if APM is acting as an OAuth Authorization Server. Consult the official F5 support article and CISA catalog for specific mitigation steps and patch availability.
