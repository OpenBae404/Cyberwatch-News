## 2. KNOWN EXPLOITED -- [CVE-2026-94127](https://nvd.nist.gov/vuln/detail/CVE-2026-94127)  
`KNOWN EXPLOITED` `CRITICAL` `CVSS 9.3` `published 2026-09-22`

> **KNOWN EXPLOITED.** CISA lists this as known-exploited in F5 BIG-IP APM on 2026-09-22, so it is being used against people now -- that outranks severity.

**What happened:** A vulnerability in F5 BIG-IP allows unauthenticated remote code execution when specific malicious traffic targets a virtual server configured with both an APM access policy and an OAuth profile acting as an Authorization Server.

**Who is affected:** Organizations running F5 BIG-IP systems where the Access Policy Manager is configured specifically as an OAuth Authorization Server are at risk, while those using APM only as an OAuth Client or Resource Server are not affected.

**How serious:** This is a critical issue with a CVSS score of 9.3 that enables full remote code execution by unauthenticated attackers, though the impact is limited to the data plane without control plane exposure.

**What to do:** Review your BIG-IP configurations to determine if the APM is functioning as an OAuth Authorization Server and apply relevant patches or mitigations provided by F5 for supported software versions.

**Why this is here:** Known exploited -- CISA lists this as known-exploited in F5 BIG-IP APM on 2026-09-22, so it is being used against people now -- that outranks severity. CRITICAL (CVSS 9.3); reach 56/100 via "big-ip".

`KNOWN EXPLOITED` `CRITICAL` `CVSS 10.0` `published 2026-08-06`

> **KNOWN EXPLOITED.** CISA lists this as known-exploited in WSO2 Multiple Products on 2026-09-24, so it is being used against people now -- that outranks severity.

**What happened:** The JWT authentication mechanism accepts tokens signed with algorithms other than those explicitly configured, allowing attackers to craft unsupported tokens that bypass validation. This flaw enables unauthorized access, including potential administrative account compromise and full account takeover.

**Who is affected:** Users of WSO2 products including Universal Gateway, Traffic Manager, API Control Plane, API Manager, and Carbon API Manager Rest API Utility.

**How serious:** The vulnerability is rated Critical with a CVSS score of 10.0, indicating a complete compromise of confidentiality, integrity, and availability. In single-tenant deployments, the impact is contained within a single security authority boundary but still carries a high severity score of 9.8.

**What to do:** Review the official WSO2 security advisory for details on mitigation and patching. Update affected products to versions that enforce strict algorithm validation for JWT tokens.

**Why this is here:** Known exploited -- CISA lists this as known-exploited in WSO2 Multiple Products on 2026-09-24, so it is being used against people now -- that outranks severity. CRITICAL (CVSS 10.0); reach unrated (no entry in the reach table).
