## 4. KNOWN EXPLOITED -- [CVE-2016-3081](https://nvd.nist.gov/vuln/detail/CVE-2016-3081)  
`KNOWN EXPLOITED` `HIGH` `CVSS 8.1` `published 2016-04-26`

> **KNOWN EXPLOITED.** CISA lists this as known-exploited in Apache Struts on 2026-10-08, so it is being used against people now -- that outranks severity.

**What happened:** A vulnerability in Apache Struts versions 2.3.19 through 2.3.28 allows remote code execution when Dynamic Method Invocation is enabled. Attackers can exploit chained expressions using the method: prefix to run arbitrary commands on the affected server.

**Who is affected:** Organizations running Apache Struts 2.3.19 to 2.3.28 with Dynamic Method Invocation enabled are directly at risk. Additionally, Huawei products including Agile Controller-Campus, AnyOffice, LogCenter, Firehunter6000, and various OceanStor firmware versions are listed as affected.

**How serious:** The issue carries a high severity rating with a CVSS score of 8.1, indicating significant potential for remote code execution. This vulnerability allows attackers to compromise confidentiality, integrity, and availability without requiring authentication.

**What to do:** Administrators should upgrade Apache Struts to a version outside the affected range or disable Dynamic Method Invocation if upgrading is not immediately possible. Users of the listed Huawei products should consult the vendor's security advisory for specific mitigation steps or patches.

**Why this is here:** Known exploited -- CISA lists this as known-exploited in Apache Struts on 2026-10-08, so it is being used against people now -- that outranks severity. HIGH (CVSS 8.1); reach unrated (no entry in the reach table).

## 5. KNOWN EXPLOITED -- [CVE-2023-22894](https://nvd.nist.gov/vuln/detail/CVE-2023-22894)  
`KNOWN EXPLOITED` `MEDIUM` `CVSS 4.9` `published 2023-04-19`

> **KNOWN EXPLOITED.** CISA lists this as known-exploited in Strapi on 2026-10-08, so it is being used against people now -- that outranks severity.

**What happened:** Strapi versions through 4.5.5 contain a vulnerability that allows authenticated attackers to infer sensitive user details by exploiting query filters on user columns. This can lead to the exposure of password hashes and reset tokens for super admins or sensitive information for lower-privileged API users.

**Who is affected:** Organizations running Strapi versions 4.5.5 and earlier that expose an admin panel to users with varying levels of access.

**How serious:** The issue is rated as medium severity with a CVSS score of 4.9, primarily impacting confidentiality rather than integrity or availability.

**What to do:** Update Strapi to a patched version beyond 4.5.5 and review access controls to ensure only necessary users have admin panel privileges.

**Why this is here:** Known exploited -- CISA lists this as known-exploited in Strapi on 2026-10-08, so it is being used against people now -- that outranks severity. MEDIUM (CVSS 4.9); reach unrated (no entry in the reach table).
