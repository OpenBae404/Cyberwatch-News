## 4. [CVE-2026-87799](https://nvd.nist.gov/vuln/detail/CVE-2026-87799)  
`CRITICAL` `CVSS 9.9` `published 2026-09-28`

**What happened:** An improper link resolution vulnerability in Canonical LXD allows authenticated users or malicious migration sources to write files as root on the host system. This is achieved by crafting rsync or btrfs send streams that plant symlinks to arbitrary paths during volume transfers.

**Who is affected:** Users running Canonical LXD versions 4.0 and later are affected until they upgrade to versions 4.0.14, 5.0.10, 5.21.8, or 6.10.

**How serious:** The vulnerability is rated Critical with a CVSS score of 9.9, enabling full host compromise and arbitrary file writes as root.

**What to do:** Upgrade Canonical LXD to version 4.0.14, 5.0.10, 5.21.8, or 6.10 to resolve the issue.

## 5. [CVE-2026-82377](https://nvd.nist.gov/vuln/detail/CVE-2026-82377)  
`CRITICAL` `CVSS 9.9` `published 2026-09-28`

**What happened:** A missing authorization check in Apache Roller 6.1.5 allows authenticated users to read, modify, or delete content in other weblogs via legacy XML-RPC APIs. The vulnerability exists because the handlers verify the caller's identity but fail to verify their permission on the specific weblog or entry being accessed.

**Who is affected:** Administrators running Apache Roller 6.1.5 who have enabled the non-default global XML-RPC setting are affected. Users of other versions or those who have not enabled this specific feature are not impacted.

**How serious:** The issue is rated Critical with a CVSS score of 9.9, indicating severe risks to confidentiality, integrity, and availability. Attackers can fully compromise data across different weblogs due to the lack of proper access controls.

**What to do:** Upgrade to Apache Roller 6.1.6 or later, which implements explicit per-method permission checks. Alternatively, keep the XML-RPC feature disabled if upgrading is not immediately possible.

**Why this is here:** Severity-chosen -- not in the CISA KEV catalogue, selected on severity and reach. CRITICAL (CVSS 9.9); reach unrated (no entry in the reach table).
