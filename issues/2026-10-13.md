## 3. KNOWN EXPLOITED -- [CVE-2016-3081](https://nvd.nist.gov/vuln/detail/CVE-2016-3081)  
`KNOWN EXPLOITED` `HIGH` `CVSS 8.1` `published 2016-04-26`

> **KNOWN EXPLOITED.** CISA lists this as known-exploited in Apache Struts on 2026-10-08, so it is being used against people now -- that outranks severity.

**What happened:** A vulnerability in Apache Struts versions 2.3.19 through 2.3.28 allows remote attackers to execute arbitrary code when Dynamic Method Invocation is enabled. Attackers can exploit chained expressions using the method: prefix to achieve this remote code execution.

**Who is affected:** Users running Apache Struts 2.3.19 to 2.3.28 with Dynamic Method Invocation enabled are directly affected. Additionally, products from Huawei such as Agile Controller-Campus, AnyOffice, Logcenter, Firehunter6000, and various OceanStor firmware versions are impacted.

**How serious:** The issue is rated as HIGH severity with a CVSS score of 8.1, indicating significant risk to confidentiality, integrity, and availability. Remote attackers can exploit this without authentication to execute arbitrary commands on the affected system.

**What to do:** Administrators should upgrade Apache Struts to a version outside the affected range or disable Dynamic Method Invocation if upgrading is not immediately possible. Organizations using the listed Huawei products should consult the vendor's security advisories for specific mitigation steps or patches.

**Why this is here:** Known exploited -- CISA lists this as known-exploited in Apache Struts on 2026-10-08, so it is being used against people now -- that outranks severity. HIGH (CVSS 8.1); reach unrated (no entry in the reach table).

## 4. KNOWN EXPLOITED -- [CVE-2023-22894](https://nvd.nist.gov/vuln/detail/CVE-2023-22894)  
`KNOWN EXPLOITED` `MEDIUM` `CVSS 4.9` `published 2023-04-19`

> **KNOWN EXPLOITED.** CISA lists this as known-exploited in Strapi on 2026-10-08, so it is being used against people now -- that outranks severity.

**What happened:** Strapi versions through 4.5.5 contain a vulnerability allowing attackers with admin panel access to infer sensitive user details by exploiting query filters. Super admins can discover password hashes and reset tokens, while lower privileged admins can expose sensitive information for API users.

**Who is affected:** Organizations running Strapi versions 4.5.5 or earlier that grant admin panel access to users. This includes environments where attackers might compromise an admin account or where admin accounts have permissions to query user data.

**How serious:** The issue is rated as medium severity with a CVSS score of 4.9, indicating a significant risk to confidentiality. Exploitation requires existing admin access, but the impact can include exposure of password hashes and sensitive user information.

**What to do:** Upgrade Strapi to a version newer than 4.5.5 to mitigate this vulnerability. Review access controls for the admin panel to ensure only authorized users have access and limit the permissions granted to lower privileged roles.

**Why this is here:** Known exploited -- CISA lists this as known-exploited in Strapi on 2026-10-08, so it is being used against people now -- that outranks severity. MEDIUM (CVSS 4.9); reach unrated (no entry in the reach table).
